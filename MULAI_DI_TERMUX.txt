APA INI
  Satu skrip yang mengerjakan SEMUA-nya sendiri di HP:
   1) cek ini benar Termux / arsitektur HP didukung
   2) pasang python, git, curl, gnupg, termux-api
   3) ambil folder proyek dari GitHub (git clone; kalau gagal,
      unduh berkasnya satu per satu -- otomatis)
   4) pasang Hermes Agent (untuk tab Chat), kunci resminya
      DIVERIFIKASI lewat sidik jari:
          C572 B5FD D1A2 9CCF A9A9 12B6 840B 0848 E139 156D
   5) aktifkan termux-wake-lock (HP tidak mematikan server)
   6) Nyalakan server dashboard, lalu BUKA browser otomatis
   7) siapkan auto-jalan saat HP reboot
   8) tampilkan RINGKASAN: berapa peringatan, berapa masalah

  Tahan-gagal: satu langkah gagal TIDAK menghentikan sisanya.
  Semua catatan disimpan di:  ~/.watchdog/mulai.log

CARA PAKAI (3 baris, copy-paste di Termux)
--------------------------------------------------------------
   pkg install -y curl
   curl -fsSL https://raw.githubusercontent.com/ninubes-ui/youtube-watchdog/main/MULAI_DI_TERMUX.sh -o mulai.sh
   bash mulai.sh

  Hasil yang dicari di akhir:
     "STATUS: BERHASIL - dashboard sudah hidup di HP ini."

  Kalau muncul "STATUS: SEBAGIAN GAGAL", kirim ke BOS NINU isi:
     ~/.watchdog/mulai.log

JIKA TOMBOL COPY DI DISCORD TIDAK BISA (jarang):
  Unduh berkas terlampir MULAI_DI_TERMUX.sh ke folder Download HP, lalu:
     cd /sdcard/Download && bash MULAI_DI_TERMUX.sh
