--------------------------------------------------------------
KENAPA KEMARIN GAGAL  (ini yang diperbaiki)
--------------------------------------------------------------
  1. Skrip setup lama pakai "set -e": begitu SATU langkah gagal,
     SEMUA langkah berikutnya ikut berhenti. Jadi kalau istilah paket
     berubah, atau internet tersendat, setup mati di tengah jalan.
     -> SEKARANG: tiap langkah dicek sendiri. Gagal satu, lanjut terus.

  2. Ada perintah "pkg update -y" DI DALAM pemasangan. Di Termux baru,
     ini bisa memunculkan prompt ketik manual -> setup nyangkut diam.
     -> SEKARANG: output prompt ditutup, dan kegagalan tidak fatal.

  3. Kunci repo Hermes diambil dari channel "stable" yang SAAT INI
     KOSONG (link-nya balas 404 / tidak ditemukan). Jadi pemasangan
     Hermes selalu gagal di situ.
     -> SEKARANG: pakai channel "canary" yang memang berisi paket
        terbaru (versi 0.21.6, ter-update 10 Okt 2026).
        Bukti terverifikasi: link canary balas HTTP 200.

  4. Tidak ada file untuk MENJALANKAN server di HP. Di laptop ada
     buka_dashboard.bat, tapi di HP tak ada padanannya.
     -> SEKARANG: ada run_termux.sh (sekali ketik, langsung cek hidup).

--------------------------------------------------------------
JANGAN JALANIN SETUP LAMA INI (sudah diganti):
     "set -e" + "pkg update -y" yang lama

APA YANG DIBUTUHKAN
  1. HP Android 64-bit (arm64) -- hampir semua HP modern.
  2. Aplikasi Termux, ambil dari F-Droid (JANGAN dari Play Store; yang
     di Play Store sudah usang dan paketnya sering gagal).
        https://f-droid.org/packages/com.termux/
  3. Internet + HP ter-colok charger.

--------------------------------------------------------------
LANGKAH (copy-paste satu per satu)
--------------------------------------------------------------
  1. Instal Termux dari F-Droid, buka aplikasinya.
     (Bonus, agar HP tak mematikan server: pasang juga app Termux:API
      dari F-Droid -- dipakai untuk perintah termux-wake-lock.)

  2. Tempel ini (satu blok):
         pkg install -y curl
         curl -fsSL https://raw.githubusercontent.com/ninubes-ui/youtube-watchdog/main/SETUP_TERMUX.sh -o setup.sh
         bash setup.sh

  3. Jalankan dashboard:
         cd ~/youtube-watchdog
         bash run_termux.sh

     Kalau muncul "[OK] server hidup (HTTP 200)" -> berhasil.
     Kalau muncul "[!!]" -> skrip otomatis menampilkan 12 baris log
     terakhir, jadi ketahuan error-nya apa.

  4. Buka browser HP:   http://localhost:8765/index.html
       - Tab Kantor + Rekomendasi: langsung jalan (cuma butuh python).
       - Tab Chat: jalan kalau langkah 4 setup berhasil (hermes ada).

  5. Cek manual kapan saja:
         curl -s http://localhost:8765/feed.json | head -c 200
         pkill -f dashboard_server.py      # matikan server

--------------------------------------------------------------
AGAR JALAN SENDIRI SAAT HP REBOOT (opsional)
--------------------------------------------------------------
     pkg install -y termux-boot
     mkdir -p ~/.termux/boot
     printf '#!/data/data/com.termux/files/usr/bin/sh\ntermux-wake-lock\ncd $HOME/youtube-watchdog\nnohup python dashboard_server.py >> server.log 2>&1 &\n' > ~/.termux/boot/start-watchdog.sh
     chmod +x ~/.termux/boot/start-watchdog.sh
  Lalu buka app "Termux:Boot" sekali supaya izinnya aktif.

--------------------------------------------------------------
JUJUR: BATASANNYA (biar tidak kaget)
--------------------------------------------------------------
  1. Paket hermes-agent di Termux masih berstatus PERCOBAAN. Dokumentasi
     resmi masih menulis "does not work right now / sedang diperbaiki".
     Channel canary yang kita pakai memang sudah terisi, tapi belum
     dijamin mulus. Kalau Chat mati:
       - Watchdog + dashboard TETAP jalan (murni Python, tanpa hermes).
       - Update paket nanti:  pkg update && pkg upgrade hermes-agent
  2. Android suka mematikan proses latar. termux-wake-lock + matikan
     "Optimasi baterai" untuk Termux membantu, TAPI tidak 100% dijamin.
  3. HP tetap harus hidup. Ini BUKAN "tanpa perangkat nyala" -- ini
     memindahkan beban dari laptop ke HP (lebih hemat listrik).
  4. Chat di dashboard butuh perintah "hermes" di HP. Jalankan
     "hermes setup" sekali untuk memasang kunci API.
